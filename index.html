THE IDEA

A different way out,
without a different machine.

Teapot makes the connections you already own available as exits. You decide which device a request goes through.

01 / CONNECT

Bring your devices

Run the agent on your computer, or turn an Android phone into an exit node over its SIM connection.

02 / APPROVE

Keep your circle small

Approve devices in the dashboard and choose which ones may offer an exit. Only approved peers can use it.

03 / ROUTE

Choose where you leave

Use the local HTTP proxy, name an exit per request, or use the Python client to pick and rotate exits.

TRY THE ROUTE

One proxy.
Many ways out.

Once two devices are approved and an exit is enabled, run the agent and send a request through the local proxy.

Read the setup guide ↗
● ● ● TERMINAL ~/teapot
# On each computer: log in, then start the agent
$ teapot login
$ teapot service install

# On your laptop: use an approved exit
$ curl -x http://127.0.0.1:1080 \
    https://ifconfig.me
The response is your exit’s public IP.
